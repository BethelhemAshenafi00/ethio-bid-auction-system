# 🚀 Ethio Bid Auction System

A full-stack web application that allows users to create auctions, place bids, and manage transactions securely. Built to simulate a real-world online auction platform with payment verification and user dashboards.

---

## 🌐 Live Demo

👉 https://ethio-bid-auction-system.vercel.app/

---

## 📌 Features

### 👤 Authentication

* User registration and login
* Role-based access (Seller / Bidder / Admin)

### 🛍️ Auction Management

* Sellers can create, update, and delete auctions
* Upload product images
* Set starting price and auction deadlines

### 💰 Bidding System

* Users can place bids on active auctions
* Real-time bid updates (UI-based)

### 📊 Dashboards

* Seller dashboard to manage auctions and view bids
* Bidder dashboard to track participation and wins

### 💳 Payment System

* Sellers provide payment method and account number
* Winning bidders upload payment proof (slip)
* Sellers can approve or reject payments

### 🖼️ Image Upload

* Integrated with Cloudinary for storing images

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/BethelhemAshenafi00/ethio-bid-auction-system.git
cd ethio-bid-auction-system
```

### 2. Install dependencies

#### Frontend

```bash
cd client
npm install
npm start
```

#### Backend

```bash
cd server
npm install
npm run dev
```
